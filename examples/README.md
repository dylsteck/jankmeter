# jankmeter Examples

| Example | Description |
|---------|-------------|
| [with-vite](./with-vite/) | Vite + React + jankmeter via Vite plugin |
| [with-nextjs](./with-nextjs/) | Next.js App Router + `<JankMeter />` component |
| [with-webpack](./with-webpack/) | Webpack 5 + React + jankmeter Webpack plugin |
| [with-script](./with-script/) | Vanilla HTML/JS + jankmeter programmatic API |

Each example has its own `package.json`. To run:

```sh
cd examples/with-vite  # or any example
bun install
bun run dev
```
